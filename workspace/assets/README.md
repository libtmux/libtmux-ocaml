# Workspace logo assets

SVG and 512 × 512 transparent PNG workspace artwork from the
[libtmux logo kit](https://github.com/libtmux/assets), revision
`ef6c550b8d1120fe6873e610ddbe550f95016a46` (`assets/ocaml/workspace`, primary
`#EF7A08`).

Workspace marks use the plain tiled tmuxp base, and language colors follow
[GitHub Linguist][linguist]. See
[`../../assets/README.md`](../../assets/README.md) for the core library mark
and sharing card.

[linguist]: https://github.com/github-linguist/linguist/blob/538da05f034fa5c83bd81df128d144e208898da3/lib/linguist/languages.yml
